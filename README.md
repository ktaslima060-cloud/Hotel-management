# 🏨 Hotel Booking & Operational Analytics

## 📌 Overview
This project performs an Exploratory Data Analysis (EDA) on hotel management and booking data to analyze guest demographics, booking trends, cancellation patterns, and revenue metrics. By combining structured data modeling with interactive exploratory analysis, this project provides actionable insights to help hotel management optimize pricing strategies, improve room occupancy, and minimize booking cancellations.
